iPhone & iPad

Installez l'application Web Docta na Tshombo sur votre écran d'accueil, comme une application.

  1. Ouvrez ce site dans Safari
  2. Touchez Partager (carré + flèche)
  3. Touchez « Sur l'écran d'accueil »
  4. Touchez Ajouter
Ce n'est pas une application iOS native : c'est une application Web installable (PWA).

Installer l'application Web sur iPhone

  1. Ouvrez ce site dans Safari.
  2. Touchez le bouton Partager en bas de l'écran.
  3. Sélectionnez « Sur l'écran d'accueil ».
  4. Touchez Ajouter. L'icône apparaîtra sur votre écran d'accueil.

L'application Web fonctionne hors ligne et s'ouvre en plein écran, comme une application native.
